# Building this

*(This process worked for me on Macbook Air M1)*

1. Make sure this specific [whisper.cpp](https://github.com/evmmc/whisper.cpp.git]) is checked out as a submodule at `./whisper.cpp`
2. Install XCode 26 Beta 
3. Load this peoject and push that Cmd-B 
4. The .app file will be in `/tmp/VoiceInk.dst/Applications`

The resulting app has the licensing checks disabled so you can use VoiceInk for free. You will still get prompts asking you whether you wanna upgrade to a new version. That version is from upstream so if you wanna continue freeloading, don't upgrade.
